# Project Brief — Nexova Solutions

## Descripción del Proyecto

Nexova Solutions es una consultora de recursos humanos y selección de talento (fundada 2011, Valencia/Miami, 120 empleados, ~$8M facturación anual). El proyecto consiste en construir **sistemas inteligentes** que permitan a Nexova hacer lo que ya hace bien — headhunting, outsourcing de soporte, formación corporativa — pero más rápido, a mayor escala y con menos esfuerzo manual.

El equipo de AI Engineering debe entregar dashboards, automatizaciones, agentes de IA y pipelines de datos para 6 departamentos clave.

## Objetivos

1. **Automatizar el screening de candidatos** — Reducir el tiempo de lectura de CVs de los 40 consultores de selección.
2. **Construir un sistema RAG** sobre la base de datos de candidatos para matching semántico.
3. **Implementar un chatbot de soporte de primera línea** que resuelva ~40% de consultas sin intervención humana (SLA: 24h).
4. **Crear dashboards ejecutivos** con KPIs en tiempo real para Laura Mendoza (CEO).
5. **Pipeline de contenido asistido por IA** para marketing.
6. **Portal de RRHH interno** con onboarding automatizado.
7. **Motor de recomendación** para programas de formación corporativa.

## Alcance

### Dentro del alcance

- Agentes de IA para operaciones, soporte, ventas, RRHH, formación
- Dashboards de telemetría y reporting
- Pipelines de datos (ETL entre sistemas dispersos)
- Integraciones con HubSpot, Zendesk legacy, Google Workspace
- RAG sobre base de candidatos

### Fuera del alcance (por ahora)

- Rediseño completo de la web corporativa
- Migración del ATS legacy a un sistema nuevo
- Desarrollo de apps móviles
